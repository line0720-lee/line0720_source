# 2026-10-22 간호도우미 3단계: 답변 규칙과 출처 표시

**상태: 완료. 실제 모델 답변 테스트 5개는 게이트웨이를 받은 뒤 진행(보류)**

## 목표
간호 규정·지침에 맞게 답변 규칙(SYSTEM_PROMPT)과 출처 표시([문서명 제N조] / [문서명 p.N] / [문서명 제목])를 바꾼다.
근거: `00_단계별_프롬프트.md` 3단계. 3~6단계는 통합 계획 하나로 승인받아 진행했다(사용자 요청: "끝까지 진행").

## 수행 내용
- `backend.py` `SYSTEM_PROMPT` 재작성(dev-backend). 규칙은 6개다:
  - 근거가 없으면 "규정에서 확인되지 않습니다"라고 답한다.
  - 출처 태그를 단다.
  - 절차는 줄을 나눠 쓴다.
  - 투약·희석·주입 속도·응급 처치 답변에는 확인 문구를 붙인다.
  - 개인정보·임상 판단 질문에는 답하지 않는다.
  - 내용이 겹치면 최신 개정일 문서를 우선한다.
  - think:False와 /no_think는 유지한다.
- `index.html` (dev-frontend)
  - 컨텍스트 머리말을 `[구간 N] 문서: 문서명 · 제N조(제목) · p.N · 개정일 YYYY-MM-DD` 형식으로 바꿨다. 없는 항목은 생략한다.
  - `highlightCites`는 대괄호 내용이 **로드된 문서명으로 시작할 때만** 출처 태그로 만든다. `[참고]` 같은 일반 대괄호는 태그가 되지 않는다. `[Q번호]` 처리는 삭제했다.
  - 참고 구간 목록에 문서명·조항·쪽·유사도를 표시한다. 행마다 data-doc/article/ps/pe 속성이 붙는다.
  - 미답변 감지 문구는 "규정에서 확인되지 않습니다", `TOP_K = 4`.
  - Q&A·이미지 잔재를 삭제했다. 이로써 1단계 보안 지적 1번(이미지 onclick 주입)이 해소됐다.
- 2단계 qa-team이 찾은 파서 오탐 4건 수정(dev-backend, 테스트 14개 추가):
  - "제2장에서…"를 장 제목으로 잡던 문제
  - "제7조(희석 기준)에 따른다."를 조항 제목으로 잡던 문제
  - PDF 표의 숫자 셀 줄을 지우던 문제
  - 개정일로 최신 날짜를 고르지 못하고, 잘못된 날짜(2026-02-31 등)를 통과시키던 문제
