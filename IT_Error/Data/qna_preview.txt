[1] 병원 전산장비 장애 대응 Q&A
[2] 정보지원팀 실무 대응 매뉴얼 (전산장비 A/S 자체처리 기준)
[3] 본 자료는 병원 내 정보지원팀이 병원운영프로그램(OCS·EMR·PACS 등) 및 전산장비를 자체 운영·A/S 처리하는 과정에서 상시 발생 가능한 전산장애 유형을 정리한 Q&A입니다. 신규 인력 교육 및 현장 대응 시 참고 자료로 활용할 수 있습니다.
[4] Ⅰ.  PC·단말기 관련
[5] Q1. PC 전원이 안 들어옵니다.
[6] A.  - 전원케이블·멀티탭 연결 및 파워서플라이 후면 스위치 확인
[7]      - 멀티탭 자체 스위치 및 두꺼비집(차단기) 트립 여부 확인
[8]      - 파워버튼·전원 LED 점등 여부 확인
[9]      - 이상 없는데도 미부팅 시 파워서플라이·메인보드 고장 의심 → 예비 PC로 교체 후 고장 PC는 벤더 A/S 접수
[10] Q2. 부팅 중 반복 재부팅되거나 블루스크린이 뜹니다.
[11] A.  - 최근 설치 프로그램·업데이트 이력 확인
[12]      - 안전모드 부팅 시도 → 정상 부팅 시 드라이버·SW 충돌 의심
[13]      - 메모리(RAM) 재장착 후 재부팅 테스트
[14]      - 반복 시 디스크 진단(chkdsk) 및 하드웨어 진단 프로그램 실행
[15]      - 하드웨어 고장 확정 시 부품 교체 또는 벤더 A/S 접수
[16] Q3. 모니터 화면이 나오지 않습니다(No Signal).
[17] A.  - 모니터 전원 및 신호케이블(HDMI/DP/VGA) 연결 확인
[18]      - 케이블 교체 테스트(케이블 자체 불량이 흔함)
[19]      - 그래픽카드 슬롯 재장착
[20]      - 예비 모니터로 교체 테스트하여 모니터·PC 문제 구분 후 고장품 A/S 접수
[21] Ⅱ.  네트워크 관련
[22] Q4. 인터넷이 안 됩니다.
[23] A.  - PC IP 상태 확인(ipconfig /all) 및 IP 재할당(release/renew)
[24]      - 랜케이블 연결 및 스위치 포트 링크 램프 확인
[25]      - 동일 스위치에 연결된 타 PC 동시 증상 여부로 스위치 장애 여부 판단
[26]      - 스위치 전원 재투입으로 1차 조치, 미해결 시 백본·회선 상태 확인
[27]      - 구간 전체 장애 시 네트워크 담당자에게 즉시 에스컬레이션
[28] Q5. OCS·EMR 접속이 느리거나 접속되지 않습니다.
[29] A.  - 네트워크 연결 상태 우선 확인
[30]      - 서버 가동 여부 및 CPU·메모리 부하 확인
[31]      - 외래 피크타임 등 동시접속자 급증 여부 확인
[32]      - 특정 PC만의 문제인지 부서 전체 공통 문제인지 구분
[33]      - 전체 장애 시 서버 담당자·벤더 동시 연락 및 유관부서 공지 검토
[34] Q6. 병동 PDA·태블릿 무선랜이 자주 끊깁니다.
[35] A.  - AP(무선접속장치) 신호세기 및 음영지역 여부 확인
[36]      - AP 간 로밍(핸드오프)·채널 간섭 설정 확인
[37]      - 단말기 Wi-Fi 드라이버·펌웨어 최신 여부 확인
[38]      - 다수 단말기 동시 증상 시 해당 구역 AP 재부팅
[39]      - 반복 발생 구역은 AP 증설 또는 설치 위치 조정 검토
[40] Q7. 특정 부서만 네트워크가 되지 않습니다.
[41] A.  - 해당 구역 스위치·AP 전원 및 랜선 연결 상태 확인
[42]      - 스위치 포트 손상 여부(타 포트 이동 테스트)로 확인
[43]      - VLAN 설정 오류 여부 점검
[44]      - 스위치 재부팅으로 1차 조치, 배선 문제 의심 시 전기·통신 배선 점검 요청
[45] Ⅲ.  프린터·주변기기 관련
[46] Q8. 프린터 인쇄가 되지 않습니다.
[47] A.  - 전원 및 케이블(USB/네트워크) 연결 확인
[48]      - 인쇄 대기열(스풀러) 확인 후 대기 문서 삭제 및 재시도
[49]      - 프린터 드라이버 재설치
[50]      - 네트워크 프린터는 IP 통신(ping) 확인
[51]      - 토너·잉크 잔량 및 하드웨어 오류 표시 확인
[52] Q9. 프린터에 용지 걸림(Jam)이 발생했습니다.
[53] A.  - 전원 차단 후 매뉴얼에 따라 걸린 용지 제거(무리하게 당기지 않음)
[54]      - 용지 상태(습기·정전기·규격) 확인
[55]      - 급지대(카세트) 용지 정렬 및 가이드 위치 확인
[56]      - 반복 발생 시 롤러 마모 점검 및 소모품 교체, 자체 조치 불가 시 벤더 A/S 접수
[57] Q10. 바코드 스캐너가 인식되지 않습니다.
[58] A.  - USB 연결 상태 확인 및 포트 변경 테스트
[59]      - 테스트 바코드로 스캐너 자체 동작 확인
[60]      - 드라이버 재설치 및 타 PC 연결 테스트로 스캐너·PC 문제 구분
[61]      - 렌즈 이물질 확인·청소, 하드웨어 고장 확정 시 예비 스캐너로 교체
[62] Q11. 전자동의서 서명패드가 작동하지 않습니다.
[63] A.  - USB 연결 및 전용 드라이버 정상 설치 여부 확인
[64]      - 서명 프로그램 재실행
[65]      - 타 PC·포트 연결 테스트로 장비·PC 문제 구분
[66]      - 펌웨어 업데이트 필요 여부 확인, 반복 고장 시 보증기간 확인 후 벤더 A/S 접수
[67] Ⅳ.  병원정보시스템(OCS·EMR·PACS 등) 관련
[68] Q12. 처방이 전송되지 않습니다.
[69] A.  - 네트워크 연결 및 서버 상태 우선 확인
[70]      - 프로그램 재접속(재로그인)으로 세션 문제 여부 확인
[71]      - 인터페이스 엔진(연동 서버) 정상 가동 여부 확인
[72]      - 타 부서 유사 증상 확인으로 전체·개별 장애 구분
[73]      - 전체 장애 시 간호부·원무과 등에 즉시 공지 및 수기 처방 절차 안내
[74] Q13. PACS 영상 조회가 느리거나 열리지 않습니다.
[75] A.  - 네트워크 대역폭·트래픽 상태 확인
[76]      - PACS 서버·스토리지 가용 용량 확인
[77]      - 뷰어 프로그램 재실행 및 캐시 삭제
[78]      - 특정 영상만의 문제인지 전체 조회 불가인지 구분
[79]      - 대용량 영상(CT/MRI) 지연은 정상 범위 여부 확인 후 필요시 벤더 문의
[80] Q14. 프로그램 업데이트 후 오류가 발생합니다.
[81] A.  - 업데이트 배포 공지 및 변경 내역 확인
[82]      - 캐시·임시파일 삭제 후 재실행
[83]      - 이전 버전 재설치(롤백) 가능 여부 확인
[84]      - 타 PC에서 동일 증상 재현 여부 테스트
[85]      - 확산 우려 시 업데이트 배포 일시 중단 및 벤더에 긴급 문의
[86] Q15. 검사장비 연동(LIS 등)에 오류가 발생합니다.
[87] A.  - 장비-PC 간 통신 케이블·네트워크 연결 확인
[88]      - 인터페이스 미들웨어(연동 프로그램) 재시작
[89]      - 장비 자체 오류 로그 확인
[90]      - 검사실 담당자와 증상 공유(특정 장비 여부 확인)
[91]      - 장비 제조사 A/S와 병원 인터페이스 벤더 동시 확인이 필요할 수 있음
[92] Q16. 원무과 수납 프로그램이 응답하지 않습니다(먹통).
[93] A.  - 작업관리자에서 응답없음 상태 확인 후 강제종료 및 재실행
[94]      - DB 서버 접속 상태 확인
[95]      - 동시 사용자 다수 접속으로 인한 지연 여부 확인
[96]      - 재실행으로 미해결 시 PC 재부팅
[97]      - 수납 업무 마비 시 임시 수기 처리 절차 안내 및 신속 복구 우선 조치
[98] Ⅴ.  서버·전원 관련
[99] Q17. 서버가 다운되었습니다.
[100] A.  - 서버실 방문하여 전원·본체 상태 육안 확인
[101]      - 서버 콘솔 접속 시도 및 하드웨어 경고등(RAID·팬·전원 등) 확인
[102]      - 이중화(클러스터/이중서버) 구성 여부 확인 후 즉시 페일오버 전환
[103]      - 원인 파악 전 무리한 강제 재부팅 지양(데이터 손상 우려)
[104]      - 장애 규모가 크면 병원 전체 공지 및 유지보수 벤더에 즉시 연락
[105] Q18. UPS(무정전전원장치)에서 경고음이 울립니다.
[106] A.  - 표시창의 경고 내용(과부하·배터리 이상·입력전원 이상 등) 확인
[107]      - 연결 부하량이 정격용량을 초과했는지 확인
[108]      - 배터리 수명(교체주기) 확인
[109]      - 경고음만으로 즉시 전원을 차단하지 말고 원인 확인 후 조치
[110]      - 이상이 지속되면 전기설비팀과 합동 점검
[111] Q19. 정전이 발생했습니다.
[112] A.  - UPS·비상발전 가동으로 핵심 서버·의료장비 전원 유지 확인
[113]      - OCS·PACS 등 주요 시스템 순단 여부 및 정상 동작 확인
[114]      - 복구 후 서버·네트워크 장비는 과부하 방지를 위해 순차적으로 재부팅
[115]      - 정전 중 처리된 데이터의 정합성 점검
[116]      - 정전 원인이 병원 내부(누전 등)인지 한전측인지 구분하여 대응
[117] Ⅵ.  보안 관련
[118] Q20. 랜섬웨어·바이러스 감염이 의심됩니다.
[119] A.  - 즉시 해당 PC의 랜케이블을 분리해 확산 차단(증거 보존을 위해 임의로 전원은 끄지 않음)
[120]      - 백신 프로그램으로 정밀검사 실행
[121]      - 공유폴더·서버 접근 이력을 확인해 확산 여부 점검
[122]      - 개인정보·의무기록 유출 가능성이 있으면 즉시 정보보호 담당자 및 상급자 보고
[123]      - 원인 파악 전 임의 삭제·포맷 금지, 필요시 현 상태를 보존해 대응
