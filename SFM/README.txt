  SFM - Smart File Manager v1.0
  로컬 파일 전문 검색 도구 (파일명 + 내용 + 한국어 초성 검색)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 시스템 요구사항
  - Windows 10 (64비트) 이상
  - .NET 런타임 불필요 (self-contained 단일 EXE)
  - 디스크 여유 공간: SFM.exe 약 80~120 MB + 인덱스 DB


■ 실행 방법

  1. SFM.exe 를 원하는 폴더에 복사합니다.
  2. SFM.exe 를 더블클릭하여 실행합니다.
  3. ⚙(설정) 버튼 → '인덱싱 경로' 탭에서 검색할 폴더를 추가합니다.
  4. '인덱싱 실행' 탭 → [지금 인덱싱 시작] 을 클릭합니다.
  5. 인덱싱 완료 후 검색창에 키워드를 입력하면 즉시 결과가 표시됩니다.


■ 최초 실행 시 UAC(관리자 권한) 안내

  SFM.exe 자체는 관리자 권한이 필요하지 않습니다.
  단, 인덱싱 경로에 시스템 폴더(C:\Windows, Program Files 등)를
  포함한 경우에는 일부 파일 접근이 제한될 수 있습니다.

  Windows Defender / 백신 프로그램이 최초 실행 시 SFM.exe 를
  검사할 수 있으며, 잠시 시간이 걸릴 수 있습니다.
  신뢰하는 경로에서 실행하시면 이후에는 빠르게 시작됩니다.


■ 인덱스 데이터 저장 위치

  %APPDATA%\SFM\sfm_index.db
  (예: C:\Users\사용자명\AppData\Roaming\SFM\sfm_index.db)

  인덱스를 완전히 초기화하려면:
    설정(⚙) → '인덱싱 실행' 탭 → [인덱스 전체 초기화]


■ 검색 기능 안내

  ┌──────────────────────┬───────────────────────────────────────┐
  │ 검색 유형            │ 예시                                  │
  ├──────────────────────┼───────────────────────────────────────┤
  │ 일반 파일명 검색     │ 보고서                                │
  │ 부분 일치            │ 2024 예산                             │
  │ 파일 내용 검색       │ 계약서 (파일 내부 텍스트 탐색)       │
  │ 한국어 초성 검색     │ ㅂㄱㅅ → '보고서' 등 일치            │
  │ 혼합 초성            │ ㅂ고서 → 초성+글자 혼합 검색         │
  └──────────────────────┴───────────────────────────────────────┘

  - 파일유형 필터 드롭다운: 전체 / 문서 / PDF / 이미지 / 소스코드
  - 검색창에 입력하면 300ms 후 자동으로 검색됩니다.
  - 결과 더블클릭: 파일 열기
  - 결과 우클릭: 파일 열기 / 파일 위치 열기 / 경로 복사


■ 파일 내용 인덱싱 지원 형식

  - 일반 텍스트:  .txt .log .csv .md .xml .json .yaml .ini .toml
                  .cs .py .js .ts .java .cpp .c .h .go .rs 등 소스코드
  - PDF:          .pdf  (pdfium 기반 텍스트 추출)
  - MS Office:    .docx .xlsx .pptx  (OpenXML 기반)
  ※ .doc / .xls 등 구버전 바이너리 형식, 이미지 파일은 내용 인덱싱 제외


■ 폐쇄망(인터넷 차단) 환경 설치 안내

  SFM.exe 는 완전한 self-contained 단일 실행 파일입니다.
  .NET 8 런타임, SQLite, pdfium 등 모든 의존성이 EXE 안에 포함되어
  인터넷 연결 없이도 설치 없이 바로 실행할 수 있습니다.

  필요한 파일:
    SFM.exe  ← 이 파일 하나만 복사하면 됩니다.


■ 문제 해결

  Q. 검색 결과가 나오지 않아요.
  A. 설정(⚙) → 인덱싱 실행 → [지금 인덱싱 시작] 을 먼저 실행하세요.

  Q. 파일 내용이 검색되지 않아요.
  A. 설정(⚙) → 검색 옵션 → '파일 내용 인덱싱 활성화' 체크 후
     [내용 인덱싱 추가 실행] 버튼을 누르세요.

  Q. 인덱싱 중 속도가 느려요.
  A. 대용량 폴더 첫 인덱싱은 파일 수에 따라 수 분~수십 분 소요됩니다.
     이후 파일 변경은 백그라운드에서 자동으로 반영됩니다.

  Q. DB 파일을 삭제하고 싶어요.
  A. SFM.exe 종료 후 아래 파일을 삭제하세요.
       %APPDATA%\SFM\sfm_index.db
