# 온프레미스 STT 변환 프로그램 설계서(案)

2026-10-28 · 이영동

> 2026-10-28 개정: 결과 저장 위치(`result\` 폴더), 대상 폴더 기억, B열 상대경로 규칙(항상 표기), 예외 처리 3건 추가

## □ 개요

사용자가 선택한 폴더의 .wav 파일 전체를 인터넷 연결 없이 로컬 STT 모델로 변환하고, 결과를 실행일자가 들어간 엑셀 파일 1개에 정리하는 Windows 데스크톱 프로그램을 만든다.

**1. 목적**

- 녹음 파일(회의, 업무 녹취 등)의 텍스트화 업무를 자동화
- 음성 데이터가 외부로 나가지 않는 완전 온프레미스(On-Premise) 처리로 보안 요건 충족

**2. 기능 요구사항**

① 폴더 선택: 사용자가 대상 폴더(예: `C:\temp\`)를 직접 선택 — 처음 실행 때 1회 선택하면 기억해 두고(`%APPDATA%\STT변환기\user_settings.ini`), 다음 실행부터 자동으로 채움. [폴더 변경] 버튼으로 언제든 변경. 저장된 폴더가 없어졌으면 다시 선택 창을 띄움

② 일괄 변환: 폴더 안의 .wav 파일을 모두 찾아 순서대로 STT 변환

③ 엑셀 출력: 실행할 때마다 엑셀 파일 1개 생성, 파일명에 변환 날짜·시각 포함

④ 셀 정리: 한 행에 1개 파일 — 왼쪽 셀에 .wav 파일명, 오른쪽 셀에 변환 내용

⑤ 시작·중지: 프로그램 실행 후 폴더를 고르고 [시작]으로 변환 시작, [중지]로 현재 파일을 끝낸 뒤 멈춤. 창을 닫으면 프로그램 종료(변환 중이면 확인 후 중지)

⑥ 진행 표시: 화면에서 눈으로 바로 확인
- 폴더를 고르면(하위폴더 옵션을 바꿔도) 시작 전에 대상 .wav 개수를 바로 표시
- 전체 진행률 바와 "n / 전체 N건 (xx%)", 처리 중인 파일명과 그 파일의 진행률
- 성공·실패 건수를 따로 표시 (실패는 빨간색)
- 파일 목록 표: 번호·파일명·상태(대기 / 변환 중 / 완료 / 실패(사유))·재생 시간·처리 시간 — 행마다 상태가 실시간으로 바뀜

**3. 비기능 요구사항**

- 인터넷 미연결(폐쇄망) 환경에서 설치·실행 가능
- 파이썬 등 별도 개발도구 설치 없이 실행파일(.exe)로 배포
- 일부 파일이 실패해도 나머지는 계속 처리, 실패 내역은 엑셀과 로그에 기록

## □ 운영 환경 및 기술 스택

Python + faster-whisper로 개발하고 PyInstaller로 실행파일화하여, 폐쇄망 PC에는 실행파일 폴더와 모델 폴더만 복사하는 구조로 한다.

**1. 운영 환경**

| 구분 | 내용 | 비고 |
| --- | --- | --- |
| OS | Windows 11 (64bit) | 일반 사용자 PC |
| 권한 | 일반 사용자(관리자 권한 없음) | 설치 프로그램·레지스트리 사용 안 함 |
| 네트워크 | 인터넷 미연결(폐쇄망) | 외부 호출 없음 |
| 처리 장치 | CPU 전용(GPU 없음), RAM 8GB 이상 | int8 연산, small·medium 모델 권장 |
| 저장공간 | 약 3GB 여유 | 프로그램 + 모델 |

※ 운영 PC는 Windows 11 일반 사용자 PC(GPU 없음)로 확정 — CPU 전용(int8)으로 운영하고, GPU 항목은 향후 GPU PC 확보 시 적용한다. 관리자 권한 없이 폴더 복사만으로 실행되게 한다.

**2. 기술 스택**

| 구분 | 선택 | 역할 |
| --- | --- | --- |
| 언어 | Python 3.11 | 개발 언어 |
| STT 엔진 | faster-whisper (CTranslate2) | Whisper 모델 로컬 추론, 원본 대비 빠르고 메모리 적음 |
| STT 모델 | Whisper medium(기본) / small / large-v3-turbo | 한국어 인식, PC 사양에 따라 선택 |
| 오디오 디코딩 | PyAV (faster-whisper 내장) | 별도 FFmpeg 설치 불필요 |
| 엑셀 | openpyxl | .xlsx 생성·서식 지정 |
| 화면(GUI) | tkinter | 폴더 선택 창, 진행률 표시 (Python 기본 포함) |
| 패키징 | PyInstaller (onedir) | 실행파일(.exe) + 라이브러리 폴더 생성 |
| 개발도구 | Claude Code | 인터넷 PC에서 코드 작성·테스트 |

**3. 대안 검토**

- C#/.NET + Whisper.net(whisper.cpp 기반): 기존 .NET 프로그램과 통합하거나 단일 exe 배포가 중요할 때 선택
- 본 설계는 개발 속도와 한국어 처리 성능을 고려하여 Python 방식을 기본안으로 한다

## □ 시스템 구조 및 처리 흐름

모델은 시작 시 1회만 불러오고, .wav 파일을 1건씩 변환할 때마다 엑셀에 1행을 기록·저장하는 반복 구조다.

```
[프로그램 실행] → [폴더 선택] → [.wav 파일 검색] → [STT 모델 로딩(1회)]
                                                        ↓
              ┌──────── 있음 · 다음 파일 ──────→ [파일 1건 STT 변환]
              │                                         ↓
        <남은 파일?> ←──────────────────── [엑셀 1행 기록·저장]
              │ 없음
              ↓
        [완료 알림 · 엑셀 파일 1개 완성]
```

변환에 실패한 파일도 엑셀에 '실패'와 사유를 1행으로 남기고 다음 파일로 넘어간다.

**1. 모듈 구성**

| 모듈 | 역할 |
| --- | --- |
| `main.py` | 화면(GUI), 폴더 선택, 진행률 표시, 시작·중지 |
| `batch_runner.py` | .wav 목록 작성, 순차 처리, 오류 격리 |
| `stt_engine.py` | 모델 로딩, 음성 → 텍스트 변환 |
| `excel_writer.py` | 엑셀 생성, 행 추가, 서식, 건별 저장 |
| `config.ini` | 모델 경로, 모델 종류, 언어 등 설정 |

※ 변환 작업은 별도 스레드에서 실행하여 처리 중에도 화면이 멈추지 않게 한다.

## □ 엑셀 결과 파일 설계

실행 1회당 엑셀 1개를 선택 폴더 안의 `result\` 폴더에 만들고, .wav 파일 1개를 1행으로 하여 파일명(B열) 옆 셀(C열)에 변환 내용을 넣는다.

**1. 파일명 규칙**

- 형식: `STT_결과_YYYYMMDD_HHMMSS.xlsx` (변환 실행 날짜·시각)
- 예시: `STT_결과_20261028_093015.xlsx`
- 저장 위치: 사용자가 선택한 폴더 안의 `result\` 폴더 (예: `C:\temp\result\STT_결과_20261028_093015.xlsx`)
  - `result\` 폴더가 없으면 만들고, 이미 있으면 그대로 사용
  - 하위폴더 검색 시 `result\` 폴더는 제외
  - .wav가 하나도 없으면 `result\` 폴더도 만들지 않음
  - 쓰기 권한은 변환 시작 전에 확인 (폴더 생성·임시 파일 쓰기 시험)
- 같은 날 여러 번 실행해도 시각이 달라 덮어쓰지 않음

**2. 시트 구성 (시트명: STT결과)**

| 열 | 항목 | 예시 | 비고 |
| --- | --- | --- | --- |
| A | 번호 | 1 | 처리 순서 |
| B | 파일명 | 회의녹음_01.wav | 필수 |
| C | 변환 내용 | 오늘 회의 안건은 … | 필수, 자동 줄바꿈 |
| D | 재생 시간 | 00:12:34 | 오디오 길이 |
| E | 처리 시간(초) | 85 | 변환 소요 시간 |
| F | 상태 | 완료 / 실패 | 실패 시 사유 기록 |
| G | 변환 일시 | 2026-10-28 09:31:40 | 행별 완료 시각 |

**3. 서식**

- 1행 머리글: 굵게, 배경색, 틀 고정 (프로그램 기본: 연한 회색 `D9D9D9`)
- C열 너비 넓게(약 100), 자동 줄바꿈, 위쪽 맞춤
- 실패 행은 F열을 빨간 글씨로 표시

**4. 처리 규칙**

① 파일 1건 처리 때마다 엑셀을 저장 — 중간에 프로그램이 멈춰도 그때까지 결과 보존

② 엑셀 셀 1칸 최대 글자 수는 32,767자 — 초과 시 C열에 앞부분을 넣고 나머지는 '전문' 시트에 나누어 저장하고, 동일 이름의 .txt 파일도 `result\` 폴더에 함께 저장

③ 하위 폴더의 파일은 항상 B열에 선택 폴더 기준 상대경로로 표기 (예: `2팀\회의녹음_01.wav`), 선택 폴더 바로 아래 파일은 파일명만 표기

## □ 단계별 구현 계획

1~6단계는 인터넷 PC(Windows)에서 Claude Code로 개발하고, 7~8단계에서 폐쇄망 PC로 반입·검증한다.

| 단계 | 작업 내용 | 산출물 | 작업 환경 |
| --- | --- | --- | --- |
| 1단계 환경 구축 | Python 3.11, 가상환경, 라이브러리 설치, STT 모델 다운로드 | 개발 환경, 모델 폴더 | 인터넷 PC |
| 2단계 STT 모듈 | 모델 1회 로딩, .wav 1건 변환 함수(한국어 고정, VAD 무음 제거) | `stt_engine.py` | 인터넷 PC |
| 3단계 일괄 처리 | 폴더 스캔(.wav, 하위폴더 옵션), 순차 처리, 실패 건 건너뛰기 | `batch_runner.py` | 인터넷 PC |
| 4단계 엑셀 출력 | 파일명 규칙, 시트·서식, 건별 저장, 32,767자 초과 처리 | `excel_writer.py` | 인터넷 PC |
| 5단계 화면(GUI) | 폴더 선택, 하위폴더 옵션, 진행률 바, 시작·중지 버튼, 완료 알림 | `main.py` | 인터넷 PC |
| 6단계 패키징 | PyInstaller onedir 빌드, 모델 경로 외부 설정 파일화 | `STT변환기\` 배포 폴더 | 인터넷 PC |
| 7단계 반입·설치 | 보안 검사 후 USB 반입, 폴더 복사, 바로가기 생성 | 설치 완료 | 폐쇄망 PC |
| 8단계 검증 | 테스트 파일 변환, 정확도·속도 확인, 사용자 안내 | 테스트 결과서 | 폐쇄망 PC |

**1. 프로그램 폴더 구조(案)**

```
STT변환기\
├─ STT변환기.exe        ← 실행파일
├─ _internal\           ← PyInstaller 라이브러리
├─ models\
│   └─ medium\          ← 사전 다운로드 모델
├─ config.ini           ← 모델 경로, 모델 종류, 언어 설정
├─ glossary.txt         ← 전문용어 목록(인식 보정용)
└─ logs\                ← 실행 로그
```

**2. 핵심 STT 설정값**

- `device="cpu"`, `compute_type="int8"`: GPU 없는 일반 PC용 설정
- `cpu_threads`: PC의 물리 코어 수로 자동 설정
- `language="ko"`: 언어 자동감지 생략으로 오인식·시간 감소
- `vad_filter=True`: 무음 구간 제거로 속도 향상, 환각(없는 말 생성) 감소
- `beam_size=5`: 정확도 우선 설정
- `initial_prompt`: `glossary.txt`의 전문용어를 넣어 고유명사 인식 보정

**3. Claude Code 활용 방법**

- 본 설계서를 프로젝트 폴더에 `design.md`로 저장한 뒤, 단계별로 "2단계 구현해줘"처럼 지시
- 단계마다 샘플 .wav로 실행 테스트 후 다음 단계 진행
- 6단계 빌드 결과물을 다른 PC(인터넷 차단 상태)에서 먼저 실행해 오프라인 동작 확인

## □ 폐쇄망 배포 절차

인터넷 PC에서 필요한 모든 파일을 미리 묶고, 폐쇄망 PC에서는 복사만으로 실행되게 한다.

**1. 인터넷 PC에서 준비**

① 모델 다운로드: Hugging Face에서 CTranslate2 변환 Whisper 모델(예: `faster-whisper-medium`) 폴더 통째로 저장

② CUDA 관련 DLL(`nvidia-cublas-cu12`, `nvidia-cudnn-cu12`)는 GPU PC용 — 본 운영 PC(GPU 없음) 배포본에서는 제외

③ PyInstaller onedir 빌드 후 `models\` 폴더를 배포 폴더에 추가

④ 인터넷 차단 PC에서 사전 실행 테스트 — 모델 다운로드 시도 등 외부 접속이 없는지 확인

⑤ 배포 폴더를 압축하고 해시값(SHA-256) 기록

**2. 반입 및 설치**

① 원내 보안 절차에 따라 반입 승인 및 백신 검사 (서명되지 않은 exe이므로 SmartScreen·백신 실행 예외 등록 요청)

② 사용자 폴더(예: 바탕화면, `D:\STT변환기\`)에 압축 해제, 해시값 대조

③ 바탕화면 바로가기 생성

**3. 오프라인 동작 보장 설정**

- 프로그램 시작 시 환경변수 `HF_HUB_OFFLINE=1` 지정 — 온라인 모델 조회 차단
- 모델은 이름이 아닌 로컬 폴더 경로로 로딩 (`config.ini`의 `model_path`)
- 업데이트 없음: 버전 변경 시 새 배포 폴더를 같은 절차로 재반입

## □ 테스트·예외처리·향후 과제

**1. 예외 처리**

| 상황 | 처리 방법 | 엑셀 표기 |
| --- | --- | --- |
| 폴더에 .wav 없음 | 안내 메시지 후 종료, 엑셀 미생성 | - |
| 손상·0바이트 파일 | 건너뛰고 다음 파일 진행 | 실패(파일 손상) |
| 음성 없음(무음) | 빈 결과로 기록 | 완료(인식된 음성 없음) |
| 엑셀 파일이 열려 있어 저장 실패 | 3회 재시도 후 `_임시저장.xlsx`로 저장, 화면·로그에 알림 | - |
| `result\` 폴더를 만들 수 없음(쓰기 권한 없음) | 변환 시작 전 안내 후 시작하지 않음 | - |
| 기억해 둔 폴더가 없어짐 | 폴더 선택 창을 다시 띄움 | - |
| 메모리 부족 | 작은 모델 사용 안내 메시지, 해당 파일 실패 처리 | 실패(메모리 부족) |
| 모델 폴더 없음 | 시작 시 경로 확인, 오류 안내 | - |
| 사용자 중지 | 현재 파일 완료 후 중단, 그때까지 결과 저장 | 미처리 건 제외 |

**2. 테스트 항목**

- [ ] .wav 1건 / 10건 / 100건 일괄 처리
- [ ] 샘플레이트·채널이 다른 .wav (8kHz 전화녹음, 44.1kHz 스테레오 등)
- [ ] 1시간 이상 긴 파일, 32,767자 초과 처리
- [ ] 한글·공백·특수문자 파일명
- [ ] 네트워크 케이블 제거 상태 실행
- [ ] 관리자 권한 없는 계정, Python 미설치 PC에서 실행
- [ ] 엑셀 열린 상태에서 실행, 중간 중지 후 결과 확인
- [ ] 실제 업무 녹음 10건으로 모델별(small·medium·large-v3-turbo) 정확도·처리 시간 확인 및 모델 확정

**3. 향후 과제**

- 화자 구분(누가 말했는지): pyannote 등 화자분리 모델 추가
- 폴더 감시 자동 변환: 새 .wav가 들어오면 자동 처리하는 상주 모드
- .mp3·.m4a 등 다른 형식 지원 (PyAV로 확장 용이)
- GPU PC 확보 시 CUDA 가속 배포본 별도 제작
- 변환 결과 요약: 원내 온프레미스 LLM과 연계하여 회의록 형태로 정리
