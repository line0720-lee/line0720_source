# STT변환기

폴더 안의 .wav 파일을 인터넷 연결 없이 로컬 Whisper 모델(faster-whisper)로 일괄 변환하여, 결과를 엑셀 파일 1개에 정리하는 Windows 데스크톱 프로그램입니다. 인터넷 PC에서 개발·빌드한 뒤 폐쇄망 PC에는 실행 폴더와 모델 폴더만 복사해 사용합니다. 자세한 설계는 `design.md`를 참고하세요.

- 운영 PC: Windows 11 64bit, 일반 사용자 권한(관리자 권한·설치 불필요), CPU 전용, RAM 8GB 이상, 여유 공간: 앱만 설치하면 약 3.1GB(앱 zip 1.4GB + 푼 앱 1.7GB, 설치 후 zip을 지우면 1.7GB), 모델 3개를 모두 풀고 zip까지 두면 약 7GB([오프라인 검증 체크리스트](verify/체크리스트.md) 전체 진행 기준)
- 폐쇄망 PC에는 Python 등 개발도구가 필요 없습니다.

## 개발 환경 준비

인터넷 PC에서 Python 3.11이 필요합니다. 프로젝트 폴더(`STT변환기`)에서 실행합니다.

```
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt -r requirements-dev.txt
```

빌드한 PC와 똑같은 패키지 버전으로 맞추려면 `requirements.txt` 대신 전체 버전을 고정한 `requirements.lock`을 씁니다.

```
.venv\Scripts\python -m pip install -r requirements.lock
```

테스트: `.venv\Scripts\python -m pytest tests -W error -q` (테스트용 .wav는 `powershell -File tests\make_samples.ps1`로 만듭니다)

## 모델 다운로드

인터넷이 되는 PC에서만 실행합니다. 모델은 `models\{모델이름}\` 폴더에 저장됩니다.

```
.venv\Scripts\python download_model.py medium small large-v3-turbo
```

인자를 생략하면 기본 모델(`medium`)만 받습니다. 사용할 수 있는 이름은 `small`, `medium`, `large-v3-turbo`입니다. 배포 압축(`tools\package.py`)에는 세 모델이 모두 있어야 합니다.

## 빌드

```
build.bat
```

PyInstaller(onedir)로 `dist\STT변환기\`를 만들고 `config.ini`·`glossary.txt`와 `config.ini`에 적힌 모델 1개(기본 medium)를 복사한 뒤, `tools\check_dist.py`로 배포 폴더를 점검합니다(23항목: 필수 DLL 있음(VC++ 런타임 4개는 `_internal\` 바로 아래), GPU 전용 CUDA DLL 없음, 모델 있음). 종료 코드 0이면 성공입니다. 점검만 다시 하려면 `.venv\Scripts\python tools\check_dist.py`.

- 최신 VC++ 재배포 패키지가 설치된 PC에서 빌드합니다(번들 DLL `vcruntime140.dll`·`msvcp140.dll` 등이 빌드 PC에서 수집됨).

## 배포 압축

```
.venv\Scripts\python tools\package.py
```

배포 폴더 점검을 먼저 하고(실패하면 압축하지 않음), `release\` 폴더에 아래 파일을 만듭니다(2~3분).

| 파일 | 크기(약) | 내용 |
| --- | ---: | --- |
| `STT변환기_앱.zip` | 1.4GB | `STT변환기\` 폴더 전체(실행파일 + 기본 모델 medium) |
| `모델_small.zip` | 430MB | `models\small\` (메모리가 적은 PC용) |
| `모델_large-v3-turbo.zip` | 1.4GB | `models\large-v3-turbo\` |
| `테스트샘플.zip` | 2MB | `테스트샘플\` 검증용 .wav 7개 |
| `SHA256SUMS.txt` | 1KB | 위 zip들의 SHA-256 해시값 |
| `README.md` | 17KB | 이 설명서의 사본(참고 문서) |
| `체크리스트.md` | 13KB | `verify\체크리스트.md`의 사본(오프라인 검증 절차, 참고 문서) |

- 앱 zip에는 빌드 결과물만 넣습니다. `dist\STT변환기`에서 시험 실행하며 생긴 `logs\`, `result\` 등은 자동으로 빠집니다.
- 해시값은 `SHA256SUMS.txt`에만 기록합니다(이 README에는 적지 않습니다). 다시 압축하면 해시값이 바뀌므로 항상 같은 번에 만든 zip과 `SHA256SUMS.txt`를 함께 가져갑니다.
- `README.md`·`체크리스트.md`는 반입한 PC에서 읽기 위한 참고 문서 사본입니다. zip 밖에 그대로 두며 `SHA256SUMS.txt`에는 넣지 않으므로 해시 대조 대상이 아닙니다(해시는 승인 대상인 zip만).

## 반입 절차

1. **인터넷 PC에서 준비**: `build.bat` → `tools\package.py`. (가능하면 인터넷이 끊긴 PC에서 먼저 [오프라인 검증 체크리스트](verify/체크리스트.md)대로 확인합니다)
2. **USB 복사**: `release\` 폴더의 zip들과 `SHA256SUMS.txt`, 참고 문서 `README.md`·`체크리스트.md`(사본, 해시 대조 대상 아님)를 복사합니다. 모델은 필요한 것만 가져가도 됩니다(앱 zip에 medium이 들어 있음).
3. **보안 절차**: 원내 반입 승인과 백신 검사를 받습니다. 서명되지 않은 exe이므로 SmartScreen·백신 실행 예외 등록을 미리 요청합니다(대상: `STT변환기.exe`와 `_internal\` 폴더).
4. **해시값 대조**: 폐쇄망 PC에 복사한 뒤 명령 프롬프트에서 파일마다 실행하고, 출력된 값을 `SHA256SUMS.txt`의 같은 파일 줄과 비교합니다. 하나라도 다르면 파일이 손상된 것이므로 다시 복사합니다.
   ```
   cd /d C:\반입
   certutil -hashfile STT변환기_앱.zip SHA256
   certutil -hashfile 모델_small.zip SHA256
   ```

## 설치(압축 풀기)

권장 위치는 **`C:\STT변환기`** (또는 `D:\STT변환기`)처럼 짧고, 일반 사용자가 쓸 수 있는 경로입니다.

- `C:\Program Files` 아래는 피합니다. 관리자 권한이 필요하고, 프로그램 폴더에 쓰지 못해 로그가 다른 곳(문서 폴더)에 남습니다.
- 바탕 화면·OneDrive 폴더처럼 경로가 길거나 동기화되는 곳도 피합니다(긴 경로에서 압축 풀기가 실패할 수 있음).

1. `STT변환기_앱.zip` 오른쪽 클릭 → **모두 압축 풀기** → 대상 폴더를 `C:\` 로 고칩니다 → `C:\STT변환기\STT변환기.exe`가 생깁니다.
   (기본으로 제안하는 `...\STT변환기_앱\` 그대로 풀면 `STT변환기_앱\STT변환기\`처럼 한 단계 더 들어갑니다. 그래도 동작에는 문제없습니다)
2. 다른 모델이 필요하면 `모델_small.zip` → 모두 압축 풀기 → 대상 폴더를 **앱 폴더** `C:\STT변환기` 로 고칩니다 → `C:\STT변환기\models\small\`이 생깁니다.
3. **바탕 화면 바로 가기**: `C:\STT변환기\STT변환기.exe` 오른쪽 클릭 → **더 많은 옵션 표시**(또는 Shift 키를 누른 채 오른쪽 클릭) → **보내기** → **바탕 화면에 바로 가기 만들기**. (exe 파일 자체를 바탕 화면으로 옮기지 마세요. `_internal\`·`models\`와 같은 폴더에 있어야 합니다)

설치 후 폴더 구조:

```
C:\STT변환기\
├─ STT변환기.exe      실행파일
├─ _internal\         프로그램 라이브러리(건드리지 않음)
├─ models\medium\     모델 (다른 모델 zip을 풀면 models\small\ 등이 추가됨)
├─ config.ini         모델 이름 설정
├─ glossary.txt       전문용어 목록
└─ logs\              실행 로그(처음 실행 때 생김)
```

## 사용 방법

1. `STT변환기.exe`(또는 바탕 화면 바로 가기)를 실행합니다.
2. **처음 실행** 때 "변환할 .wav 파일이 있는 폴더를 선택하세요" 창이 뜹니다. 폴더를 고르면 기억해 두었다가 다음 실행부터 자동으로 채웁니다. 기억한 폴더가 없어졌으면 다시 선택 창이 뜹니다.
3. 다른 폴더로 바꾸려면 **[폴더 변경]**을 누릅니다.
4. 하위 폴더의 .wav까지 변환하려면 **하위폴더 포함**을 체크합니다(하위폴더 포함 체크는 기억하지 않습니다. 다시 실행하면 풀려 있습니다). 폴더를 고르거나 체크를 바꾸면 대상 .wav 개수와 목록이 바로 표시됩니다.
5. **[시작]**: 모델을 불러온 뒤(수 초) 파일을 하나씩 변환합니다. 전체 진행률, 현재 파일 진행률, 성공·실패 건수(실패는 빨간색), 파일별 상태(대기 / 변환 중 / 완료 / 실패(사유))·재생 시간·처리 시간이 표시됩니다.
6. **[중지]**: 지금 변환 중인 파일을 끝낸 뒤 멈춥니다. 그때까지의 결과는 저장되어 있습니다.
7. 창을 닫으면 프로그램이 끝납니다. 변환 중이면 "현재 파일을 끝낸 뒤 종료할까요?"라고 묻습니다. **예**를 누른 뒤 기다리는 동안 창을 한 번 더 닫으면 "기다리지 않고 바로 종료할까요?"라고 묻고, **예**를 누르면 바로 종료합니다(이미 끝난 파일의 결과는 저장되어 있고, 지금 변환 중이던 파일의 결과만 빠집니다).
8. 끝나면 완료 알림이 뜨고, **[결과 파일 열기]**로 엑셀을 엽니다.

**결과 파일**: `선택한 폴더\result\STT_결과_YYYYMMDD_HHMMSS.xlsx` (실행할 때마다 새 파일, 날짜·시각이 달라 덮어쓰지 않음)

| 열 | A | B | C | D | E | F | G |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 항목 | 번호 | 파일명 | 변환 내용 | 재생 시간 | 처리 시간(초) | 상태 | 변환 일시 |

- B열: 하위 폴더 파일은 선택 폴더 기준 상대경로(예: `2팀\회의녹음_01.wav`)로 적습니다.
- F열: `완료` / `완료(인식된 음성 없음)`(무음) / `실패(사유)`(빨간 글씨). 손상·0바이트 파일은 `실패(파일 손상)`으로 남기고 다음 파일로 넘어갑니다.
- 파일 1건을 처리할 때마다 저장하므로 중간에 멈춰도 그때까지의 결과가 남습니다.
- 엑셀 셀 1칸에는 32,767자까지 들어갑니다. 넘으면 C열에는 앞부분만 넣고, 전체 내용은 **'전문' 시트**에 나누어 넣고, **.wav 파일 이름으로 된 .txt 파일**도 `result\` 폴더에 저장합니다(예: `회의.wav` → `회의.txt`, 하위 폴더 파일은 `\`가 `_`로 바뀌어 `2팀\회의.wav` → `2팀_회의.txt`. 같은 이름이 이미 있으면 실행 시각을 붙임). txt를 저장하지 못하면(경로가 너무 긴 경우 등) 화면·로그에 알리고 다음 파일로 넘어갑니다. 이때 C열 끝에 전체 내용은 '전문' 시트에만 있다고 적습니다.
- `result\` 폴더는 하위폴더 검색에서 빠집니다. .wav가 하나도 없으면 결과 파일을 만들지 않습니다.

## 명령줄 모드

화면 없이 변환할 수 있습니다(예약 작업·일괄 처리용). 명령 프롬프트에서:

```
cd /d C:\STT변환기
start /wait "" STT변환기.exe --folder D:\녹음 --no-gui --subfolders
echo %errorlevel%
```

- **`start /wait ""`를 꼭 붙입니다.** 이 exe는 화면용(콘솔 없음)이라 그냥 실행하면 명령 프롬프트가 끝나기를 기다리지 않고 바로 다음 줄로 넘어가, 종료 코드도 확인할 수 없습니다.
- 옵션: `--folder <폴더>`(또는 폴더를 그냥 적어도 됨) · `--no-gui`(명령줄 모드) · `--subfolders`(하위폴더 포함) · `--model small|medium|large-v3-turbo`(config.ini 대신 이 모델로, 시험·비교용)
- 종료 코드(`echo %errorlevel%`): **0** = 모두 성공, **1** = 실패한 파일이 있거나 중간에 멈춤, **2** = 시작하지 못함(폴더 없음, .wav 없음, 모델 없음, 인자 오류 등)
- 진행 문구는 명령 프롬프트 창과 로그 파일에 남습니다.

## 모델 바꾸기

1. 필요한 모델 zip(예: `모델_small.zip`)을 앱 폴더(`C:\STT변환기`)에 풀어 `models\small\model.bin`이 있게 합니다.
2. `config.ini`를 메모장으로 열어 `name =` 값을 바꾸고 저장합니다.
   ```
   [model]
   ; small / medium / large-v3-turbo
   name = small
   ```
3. 프로그램을 다시 실행합니다. 모델 폴더가 없으면 시작할 때 오류 안내가 뜹니다.

| 모델 | 특징 |
| --- | --- |
| small | 가장 빠르고 메모리를 적게 씀. 정확도는 낮은 편 |
| medium | 기본값. 속도와 정확도의 균형 |
| large-v3-turbo | 정확도 우선. 이 PC에서는 medium과 비슷하거나 조금 빠름(아래 표) |

## 용어집(glossary.txt)

자주 나오는 고유명사·전문용어를 한 줄에 하나씩 적으면 인식을 보정합니다(UTF-8로 저장). 녹음 앞부분 인식에 주로 작용하고, 긴 녹음의 뒷부분에서는 효과가 약해집니다(대략 처음 1분 정도 분량이 지나면 용어집 대신 앞에서 인식한 문장이 참고됩니다). `#`으로 시작하는 줄은 무시합니다. 너무 길면 앞부분만 사용하고 로그에 경고를 남깁니다. 고친 뒤 프로그램을 다시 실행하면 적용됩니다.

## 모델별 처리 시간

`tools\benchmark.py`로 측정한 값입니다(2026-10-29). 실시간 배수 = 처리 시간 ÷ 재생 시간 (0.40이면 10분 녹음을 약 4분에 처리).

- 측정 PC: Intel Core Ultra 7 256V (8코어 / 8스레드), RAM 15.5GB, Windows 11, CPU 전용(int8)
- 측정 파일: `기본_16k.wav`(15.4초), `긴파일_5분.wav`(`기본_16k.wav`를 20번 이어 붙인 5분 08초 파일)

| 모델 | 파일 | 재생 시간 | 모델 로딩 | 처리 시간 | 실시간 배수 |

| small | 기본_16k.wav | 15.4초 | 1.1초 | 2.7초 | 0.18 |

| medium | 기본_16k.wav | 15.4초 | 2.8초 | 5.9초 | 0.38 |

| large-v3-turbo | 긴파일_5분.wav | 5분 08초 | 2.8초 | 1분 31초 | 0.30 |

- 짧은 파일(`기본_16k.wav`) 행은 모델마다 첫 번째로 변환한 파일이라, 한 번만 하는 준비(VAD 모델 로딩 등) 시간이 들어가 실시간 배수가 실제보다 약간 크게 나옵니다. 긴 파일 행이 실제 사용에 더 가깝습니다.
- 대략 medium 기준 1시간 녹음 ≈ 25분 처리입니다. 운영 PC의 CPU·전원 모드(배터리/절전)·발열에 따라 달라지며, 같은 PC에서도 실행마다 수십 % 차이가 날 수 있습니다.
- 모델 로딩 시간은 모델 파일이 이미 메모리 캐시에 있을 때의 값입니다. PC를 켠 뒤 처음 실행하거나 느린 디스크에서는 더 걸립니다.
- 다시 측정: `.venv\Scripts\python tools\benchmark.py --models small medium large-v3-turbo` (`tests\samples\긴파일_65분.wav`가 있으면 그것도 측정합니다)

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| "Windows의 PC 보호" 파란 창(SmartScreen) | **추가 정보** → **실행**. 서명되지 않은 프로그램이라 뜰 수 있습니다. 매번 뜨면 보안 담당자에게 예외 등록을 요청합니다. |
| 백신이 실행을 막거나 파일을 지움 | 보안 담당자에게 `C:\STT변환기\` 폴더(`STT변환기.exe`, `_internal\`) 실행 예외 등록을 요청하고, 지워졌으면 다시 압축을 풉니다. |
| "메모리가 부족했습니다" / 실패(메모리 부족) | 다른 프로그램을 닫고 다시 하거나, [모델 바꾸기](#모델-바꾸기)대로 `name = small`로 바꿉니다. |
| "모델 폴더를 찾을 수 없습니다" | `config.ini`의 `name`과 `models\{이름}\model.bin`이 맞는지 확인합니다. 모델 zip을 앱 폴더 안에 풀었는지 확인합니다. |
| 결과 파일 이름이 `..._임시저장.xlsx` | 결과 엑셀이 열려 있어 저장하지 못했습니다(여러 번 다시 시도한 뒤 다른 이름으로 저장, 화면·로그에 알림). 변환 중에는 결과 파일을 닫아 둡니다. |
| "결과 폴더에 쓸 수 없습니다" | 선택한 폴더 안에 `result\` 폴더를 만들 권한이 없습니다. 쓸 수 있는 폴더(예: 내 문서 아래)로 .wav를 복사해 변환합니다. |
| 대상 .wav가 0건 | 확장자가 .wav인지, 하위 폴더에 있다면 **하위폴더 포함**을 체크했는지 확인합니다. |
| 명령줄 모드가 바로 끝나고 `%errorlevel%`이 이상함 | `start /wait ""`를 붙였는지 확인합니다([명령줄 모드](#명령줄-모드)). |

**로그 위치**: `C:\STT변환기\logs\YYYY-MM-DD.log` (날짜별). 프로그램 폴더에 쓸 수 없으면 `문서\STT변환기\logs\`에 남습니다. 오류를 문의할 때 이 파일을 함께 전달합니다.

**마지막 폴더 기억 초기화**: 기억한 대상 폴더는 `%APPDATA%\STT변환기\user_settings.ini`에 있습니다. 탐색기 주소창에 `%APPDATA%\STT변환기`를 입력해 이 파일을 지우면 다음 실행 때 처음처럼 폴더 선택 창이 뜹니다.
